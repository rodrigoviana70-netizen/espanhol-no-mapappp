# Espanhol Visual Map

Quero que você crie uma página de vendas completa, moderna, extremamente profissional e responsiva para um produto digital chamado:

ESPANHOL NO MAPA

A página deve seguir como REFERÊNCIA PRINCIPAL a página “Inglês no Mapa” mostrada na imagem que estou fornecendo.

IMPORTANTE:

Não quero apenas uma página inspirada.

Quero manter a mesma lógica de estrutura, hierarquia visual, espaçamento, alternância de seções claras e escuras, cards, CTAs, prova social, planos, garantia, FAQ e popup de oferta.

Porém, todo o conteúdo deve ser adaptado para o produto “Espanhol no Mapa”.
